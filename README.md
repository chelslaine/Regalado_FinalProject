# One Tap One Life
### Jesus on the Go Information Site

## About the Project
One Tap One Life is a digital information website created to connect donors and volunteers with Jesus on the Go, a community outreach organization based in Parañaque.

## Website Purpose
The website aims to make it easier for people to learn about the organization's outreach activities, prepare donations, arrange deliveries, and participate in community programs.

## Features
- Home page
- About section
- How to Donate section
- Contact section
- Responsive website design
